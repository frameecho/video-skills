# 参考视频分析

先通过 ffprobe 取得时长/尺寸，再用 inspect_media.py 在开头、发展、高潮、结尾及转场两侧取帧。等距采样仅用于粗览，不足以判断运动。观看短片段，记录窗口运动方向、缓动、切换速度、停留与音乐关系。

输出 `style-analysis.md`，至少写清：

| 维度 | 要记录的证据 |
| --- | --- |
| 媒介 | 像素、剪纸、手绘、摄影、桌面界面，是否混合 |
| 构图 | 主体占比、留白、窗口层级、前后景、视线焦点 |
| 色彩/材质 | 背景与强调色、颗粒、纸边、像素单位；测量和目测分开 |
| 字体 | 衬线/无衬线、字重、歌词大小、换行、关键词强调 |
| 运动 | 平移/缩放/视差/窗口开合、速度、镜头连接方式 |
| 节奏 | 音乐段落中的密度变化，已验证的时间点 |
| 标识 | 可重绘的通用界面语法与需去除的账号/平台水印 |

附至少三个时间点的参考帧与对应样片帧。用同样画幅并排比较：如果参考主体是桌面窗口，而样片主体成了全屏风景，即使颜色相同也必须返工。

让 Claude 从参考中归纳视觉规则并创作新场景。不要逐帧复制参考画面、人物或专属标识。用户给予创作自由时，让 Claude 自行选人物、叙事和镜头节奏，只保留参考分析所证明的视觉语言约束。
